## Zenodo record license

- If the record type is **Publication / Technical note**, select **CC BY 4.0**; the code inside `code/` remains GPL-3.0-only and the documentation remains Apache-2.0.
- If the record type is **Software**, select **GPL-3.0-only**; the paper remains CC BY 4.0.
